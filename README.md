## 家醫群島｜台灣家庭醫學醫學會 115 年度秋季學術研討會

把秋季會的講題依主題畫成九座島的互動網站，點進島嶼可深入各講題的下滾式頁面。

| 檔案 | 頁面 |
|---|---|
| `index.html` | 外框：在同一個畫面中載入各頁，讓連結在 claude.ai 與 GitHub Pages 都能運作 |
| `home.html` | 大綱頁（群島地圖） |
| `type2-diabetes.html` | 年輕發病第二型糖尿病 |
| `obesity.html` | 減重與長期維持 |
| `atrial-fibrillation.html` | 心房顫動中風預防 |
| `ldl-c.html` | 為何 LDL-C 仍未達標 |
| `sleep.html` | 失眠與睡眠呼吸中止 |
| `myofascial-pain.html` | 肌筋膜疼痛症 |
| `sarcopenia.html` | 2025 肌少症 |

網址 hash 對應：`#metabolic` 等島名開啟大綱頁的島嶼，`#obesity` 開啟深入頁，`#obesity--c9` 跳到該頁章節。

純靜態 HTML，由 GitHub Pages 從 `main` 分支根目錄發布。
